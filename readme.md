# Atividade Prática 2 - Desenvolvimento de Página Pessoal

Este repositório contém a entrega da Atividade Prática 2 da disciplina GAC116 - Programação Web.

O projeto consiste em um Portfólio Pessoal desenvolvido em duas versões, garantindo que o conteúdo seja equivalente em ambas, conforme os requisitos da atividade.

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla)
- **Framework 1:** Bootstrap 5
- **Framework 2:** Tailwind CSS

## Funcionalidades
- Layout Responsivo
- Funcionalidade de alternância entre Tema Claro e Tema Escuro (implementada via JavaScript em ambas as versões)
- Informações reais de perfil, formação e experiência profissional.
